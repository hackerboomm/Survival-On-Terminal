main.py contains structure of the game. Its like main machine of this terminal game.
globalEvents.py stores sets of different events like coming upon a tree. Seeing person on the way
globalPersons.py file describes persons to globalEvents.py. For this release this file only has Pamuk The Cat person (which is a cat surprisingly).
userInventory.py stores data for the inventory and has functions for inventory changes like crafting a stone axe in a camp, amount of logs stored in inventory, amount of rocks stored inside.

THIS IS A TERMINAL GAME
You need any code editor with Python terminal to run it.
You only hit the run button whatever is your editor.
